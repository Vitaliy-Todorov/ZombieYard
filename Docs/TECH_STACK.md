# ZombieYard · пакеты и плагины

**Что установить для v1.** В текущем проекте дополнительных установок не требуется. Unity версии `6000.3.22f1` совпадает с редактором Worldseed. Перечисленные ниже пакеты сверены с манифестом, файлом разрешённых зависимостей и локальным кэшем ZombieYard на 18 ноября 2026 года. [Версия редактора](../ProjectSettings/ProjectVersion.txt) · [Манифест](../Packages/manifest.json) · [Зафиксированные зависимости](../Packages/packages-lock.json)

| Уже есть в ZombieYard | Версия | Роль в проекте |
| --- | --- | --- |
| Universal RP · `com.unity.render-pipelines.universal` | 17.3.0 | Рендер участка и оружия. ExteriorFog использует текстуру глубины камеры URP |
| Input System · `com.unity.inputsystem` | 1.20.0 | Ввод от первого лица. В карте Player уже есть Move, Look, Attack, Interact, Jump, Previous, Next и Sprint |
| VContainer · `jp.hadashikick.vcontainer` | 1.19.0, Git-тег | Сборка зависимостей сцены и время жизни сервиса спавна |
| AI Navigation · `com.unity.ai.navigation` | 2.0.14 | Пакет установлен. В игровом прототипе WalkerRoutes строит пути по опорам и свободным объёмам блочной сетки YardGrid |
| Test Framework · `com.unity.test-framework` | 1.6.0 | EditMode проверяет здоровье и инвентарь. PlayMode проверяет бой, устройство ям, подбор и спавн в сцене Yard |
| MCP for Unity · `com.coplaydev.unity-mcp` | Локально 10.3.0, в манифесте ветка `main` | Инструмент агента для работы с редактором. Точную Git-ревизию текущей установки хранит lock-файл |

На новом рабочем месте открой проект указанной версией Unity и дождись восстановления зависимостей Package Manager по манифесту и lock-файлу. Для VContainer и Unity MCP используются Git-источники. После восстановления проверь версии в Package Manager. Подключение агента к редактору проверяется отдельно, когда задача требует работы через MCP.

При изменении навигации проверь путь зомби через образовавшийся проём и перелезание на границе допустимой высоты. [Реализация сетки](../Assets/General/Scripts/Components/World/YardGrid.cs) · [План проверки](ROADMAP.md)

## Когда пригодятся другие пакеты Worldseed

| Пакет из Worldseed | Решение для ZombieYard |
| --- | --- |
| R3, NuGetForUnity | Для события обнуления HP достаточно C#-события. Вернуться к R3 при появлении нескольких зависимых состояний интерфейса. NuGetForUnity имеет смысл при конкретной NuGet-зависимости |
| UniTask | Интервал спавна и перезарядка укладываются в таймеры их владельцев. Рассмотреть при появлении асинхронной загрузки с отменой |
| DOTween | Рассмотреть для конкретной анимации интерфейса или оружия. Время атаки и перезарядки хранит игровая логика |
| Tri Inspector | Стандартного инспектора достаточно для восьми типов конфигов. Вернуться при конкретной проблеме их редактирования |
| Addressables, Localization | Для одного участка подходят прямые ссылки на префабы и конфиги. Отдельные пакеты понадобятся при постановке задачи на независимую загрузку контента или поддержку нескольких языков |
| Splines, Visual Effect Graph | Рассмотреть при появлении задачи на кривые или сложные визуальные эффекты |
